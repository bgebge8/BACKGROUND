# 대학생이던 내가 이세계에서는 탑을 오르는 용사라고요?!

> 보스의 공격을 읽고, 패링으로 기회를 만들고, 반격으로 탑을 돌파하세요!

**[Windows 게임 다운로드](https://github.com/bgebge8/BACKGROUND/releases/download/v1.0/BACKGROUND.zip)** · [릴리스 페이지](https://github.com/bgebge8/BACKGROUND/releases/tag/v1.0)

## 게임 소개

**「대학생이던 내가 이세계에서는 탑을 오르는 용사라고요?!」**는 이세계의 탑을 오르며 각 층의 보스에 도전하는 **2D 탑다운 보스 액션 게임**입니다.

서로 다른 공격 패턴을 가진 보스들을 상대로 이동과 대시로 공격을 피하고, 타이밍과 방향을 맞춘 패링으로 반격의 기회를 만들어야 합니다. 보스를 쓰러뜨리고 힘을 얻으며 다음 층에 도전해 보세요.

## 게임의 특징

- **패링과 수동 반격**: 공격을 받아낸 뒤 직접 조준하고 반격하는 전투가 핵심입니다.
- **층마다 달라지는 보스전**: 검 보스, 마법소녀, 무희 듀엣, 드론 과학자, 흑월 보스가 각기 다른 패턴으로 플레이어를 맞이합니다.
- **보스 격파와 성장**: 보스를 쓰러뜨린 뒤 힘을 흡수하고 변화하는 검과 보상을 만나볼 수 있습니다.
- **픽셀 아트와 전투 연출**: 층별 배경, 보스 등장 연출, 공격 효과로 각 전투의 개성을 표현했습니다.

## 조작법

| 입력 | 동작 |
| --- | --- |
| `W` `A` `S` `D` | 이동 |
| 마우스 이동 | 조준 및 바라보는 방향 변경 |
| 마우스 왼쪽 클릭 | 공격 / 패링 성공 후 수동 반격 |
| 마우스 오른쪽 클릭 | 패링 |
| 마우스 오른쪽 버튼 유지 | 방어 |
| `Shift` | 대시 |
| `Space` 또는 `E` | 층 선택 화면에서 입장 |
| `Esc` | 일시정지 |

### 전투 팁

보스의 공격 예고를 살펴보고 회피할지, 패링할지 판단하세요. 패링에 성공했다면 마우스로 반격 방향을 조준한 뒤 **왼쪽 버튼을 새로 클릭**해 반격하세요.

## 실행 방법

**플랫폼: Windows 64비트 / 조작: 키보드·마우스**

1. 게임 배포 ZIP 파일의 압축을 모두 해제합니다.
2. 압축을 푼 폴더에서 `TowerPrototype.exe`를 실행합니다.
3. 메인 화면에서 게임을 시작합니다.

`TowerPrototype.exe`와 함께 제공되는 `TowerPrototype_Data` 폴더, DLL 및 기타 파일은 같은 배포 폴더에 그대로 두어야 합니다.
