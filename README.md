## 🏰 게임 소개
<img width="600" alt="IMAGE_MAIN" src="https://github.com/user-attachments/assets/c24b5992-97f7-4ce6-a2d5-6dd97cae6bf9" />

평범한 대학생이던 내가, 이세계에서는 탑을 오르는 용사?!

「대학생이던 내가 이세계에서는 탑을 오르는 용사라고요?!」는 이세계의 탑을 오르며 각 층의 보스에 도전하는 **2D 탑다운 보스 액션 게임**입니다.

서로 다른 공격 패턴을 가진 보스들을 상대로 이동과 대시로 공격을 피하고, **타이밍과 방향을 맞춘 패링**으로 반격의 기회를 만들어야 합니다. 보스를 쓰러뜨리고 힘을 얻으며 다음 층에 도전해 보세요.

| 👁️ 패턴 읽기 | 🛡️ 패링하기 | ⚔️ 반격하기 |
| :--- | :--- | :--- |
| 보스마다 다른 공격 패턴을 파악하세요. | 타이밍과 방향을 맞춰 기회를 만드세요. | 패링 성공 후 직접 공격해 반격하세요. |

## 🎮 조작법

| 입력 | 동작 |
| :--- | :--- |
| <kbd>W</kbd> <kbd>A</kbd> <kbd>S</kbd> <kbd>D</kbd> | 이동 |
| 마우스 이동 | 조준 및 바라보는 방향 변경 |
| 마우스 왼쪽 클릭 | 공격 / 패링 성공 후 수동 반격 |
| 마우스 오른쪽 클릭 | 패링 |
| 마우스 오른쪽 버튼 유지 | 방어 |
| <kbd>Shift</kbd> | 대시 |
| <kbd>Space</kbd> 또는 <kbd>E</kbd> | 층 선택 화면에서 입장 |
| <kbd>Esc</kbd> | 일시정지 |

## 📦 실행 방법

**Windows 64비트 · 키보드와 마우스 필요**

1. **[릴리스 페이지](https://github.com/bgebge8/BACKGROUND/releases/tag/v1.0)**에서 게임 배포 ZIP 파일을 다운로드합니다.
2. ZIP 파일의 **압축을 모두 해제**합니다.
3. 압축을 푼 폴더에서 **`TOWER.exe`**를 실행합니다.
4. 메인 화면에서 게임을 시작합니다.
